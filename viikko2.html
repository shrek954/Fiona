Viikko 2

Tämän viikon tehtävänä oli rakentaa GitHub Actions -workflow, joka analysoi repositorion sisältöä automaattisesti.

Sisältö

Tehtävässä luotiin GitHub Actions -workflow sekä analyysiskripti repositorion tutkimista varten.

Workflow suoritetaan automaattisesti aina, kun repositorioon tehdään push tai pull request.

Analyysiskripti tunnistaa repositoriossa käytettyjä ohjelmointikieliä ja etsii koodista yleisiä ohjelmistosuunnittelun malleja heuristiikoiden avulla.

Analyysin tulokset tulostetaan GitHub Actions -lokiin ja tallennetaan analysis_report.txt-tiedostoon, joka julkaistaan artefaktina.
